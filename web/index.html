Пароли из seed-фразы

Пароль для каждого сайта вычисляется из вашей BIP39 seed-фразы, домена и логина. Хранить пароли не нужно: после потери устройства они восстанавливаются из той же фразы.

Seed-фраза не сохраняется. На устройстве останется только ключ, зашифрованный мастер-паролем (Argon2id). Забытый мастер-пароль не восстановить, войти можно будет только seed-фразой, поэтому её всё равно нужно хранить на бумаге.

Запишите фразу на бумагу и храните офлайн. Используйте отдельную фразу, а не ту, на которой лежат криптоактивы.

  • Всё считается в браузере. Seed-фраза и пароли не отправляются в сеть: политика безопасности страницы запрещает любые внешние запросы.
  • Seed-фраза не сохраняется. Открытый ключ живёт только в памяти вкладки и стирается после 5 минут бездействия. Вход по логину хранит на устройстве лишь ключ, зашифрованный мастер-паролем.
  • Совместимо. Те же пароли выдают CLI pm и расширение для браузера. Исходный код и спецификация.
